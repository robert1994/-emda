WITH THE MOUSE

Drag a knob up or down, or use the scroll wheel over it. Click an encoder to push it. Push and turn (it edits the smaller value on that card): double-tap an encoder and its push stays held (it glows), then drag, scroll the trackpad or use ← →; tap it again to let go. Shift + drag or Shift + wheel also works. Line 1 picks the sound and Line 2 sets the reverb; hold PLAY (or Space) while moving them to set the two input levels instead. Hold PLAY for 1.5 s (without moving a knob) for the FX + LINES pages: generation loss, tape echo, shimmer reverb and the line inputs / outputs; hold PLAY again or press MENU to go back. Hold LATCH for the INPUT LAB: a sampler, a pitch follower (harmony / MIDI out) and a granular freeze for what comes into the line inputs (use "Play a file into Line 1" to try it). Click the yellow buttons; hold MENU for the USB update screen.

MIDI KEYBOARD

Plug a MIDI keyboard into this computer. It works when this page is opened as a file in Chrome or Edge.

This runs the real Hemda firmware: the same sound engine and screen code that go onto the ESP32-S3, compiled for the browser. Settings and presets you make here are kept in this browser.

Every change here goes to the emulator on the other tab. Switch to Hemda on USB-C to manage the real synth.

FIRMWARE

Writes firmware over the USB-C cable (no buttons needed), or over Bluetooth (about 2 minutes; the synth asks you to push encoder 1 first). Settings and presets are kept. Needs Chrome or Edge on a computer, or Chrome on Android for Bluetooth.

Built-in firmware: 1.4.0 (hemda-full.bin). For a USB stick instead, copy hemda.bin to /HEMDA/FIRMWARE/ and hold MENU.

CONSOLE

Any HEMDA.TXT command, for example map latch long panic, param reverb 0.8, note 60 on.
