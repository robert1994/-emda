The real firmware, the same sound engine and screen code that run on the ESP32-S3, compiled for the browser. Nothing to install.

Edit

Connect the synth over USB-C in Chrome or Edge: every parameter, the 8 presets, button mapping, knob jobs, settings and the device log.

Update

Install the firmware file that comes with your Ħemda in about 20 seconds, read back and checked. Settings and presets survive updates.

Open Hemda Studio

Controls

Five pages, each with a top and a bottom row. ROW DOWN steps top row → bottom row → next page. Each encoder edits the big value on its card; push and turn edits the other row.

Line 1 knobInstrument: Velvet Pad, Soft Tines and the rest
Line 2 knobReverb mix
Hold PLAYLine 1 / Line 2 set the two input levels
Tap PLAYGenerative playing on / off
MENUSettings, presets, knob jobs. Hold: USB-stick update
Bluetooth MIDIPairs as “Ħemda XXXX” with an iPad, Mac, PC or Android: play it wirelessly, or use it as a wireless MIDI interface

Every button's press and hold, and both Line knob jobs, can be changed without new firmware.

Firmware

First install, over USB-C

  1. Switch the synth on and plug USB-C into the computer.
  2. Open Hemda Studio → Manager in Chrome or Edge.
  3. Click Install a .bin file, choose the hemda-full.bin that came with your Ħemda, and pick the “USB-SERIAL CH340” port.

Later updates, from a USB stick

  1. Copy the hemda.bin update you received to /HEMDA/FIRMWARE/ on a FAT32 stick.
  2. Plug it into the USB-A port and hold MENU for 1.5 s.
  3. Check the version, push encoder 1. If the new firmware fails, the old one comes back by itself.

Firmware files are sent to Ħemda owners directly, they are not downloadable here.
